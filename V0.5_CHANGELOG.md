# Echo Clash Online V0.5 Changelog

## Experience layer
- Added a true Main Menu.
- Added New Game and Join Game routes.
- Added an in-app Rule Book.
- Added a live Card Encyclopedia fed from the server card catalogue.
- Added a seven-step guided Tutorial Match.
- Added a Resume previous room entry on the menu.
- Added in-match Rule Book access.

## Gameplay rule change
- Every scheduled turn now automatically draws 1 card, up to the 15-card hand cap.
- Draw Action remains +3 additional cards.

## Readability
- Added persistent P1–P8 player colors.
- Added P-number labels so color is never the only identifier.
- Applied player identity to lobby seats, turn order, battlefield pods, Battle Log and legend.
- Added a Latest Event panel to the battlefield.
- Added turn-start draw reminders in lobby and match UI.

## Deferred intentionally
- Accounts, persistent profiles and match history: V0.6.
- Full battle/performance animation system: V0.7.
